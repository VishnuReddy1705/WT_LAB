# Experiment 08: Modern User Interface Design using ReactJS

**Course:** 23CS2029 – Web Technology Lab  
**Student Register Number:** URK24CS1163  

---

## 📌 Aim
To design and develop a modern, responsive user interface using ReactJS by applying the following concepts:
- React components
- JSX
- Props
- State (`useState`)
- Event handling
- CSS styling
- Responsive design
- Reusable UI components

---

## 🚀 Features Implemented
1. **Navigation Bar:** Branded as `EduDashboard URK24CS1163` with nav-links, live search bar, notification drawer with badges, and student profile picture.
2. **Theme Switcher:** Seamless Light Mode / Dark Mode toggling using React state.
3. **Stat Cards Grid:** 4 reusable `StatCard` components showing Courses, Assignments, Attendance (92%), and dynamically computed overall Course Completion percentage.
4. **Interactive Course List:** Displays courses with dynamic `ProgressBar` components and real-time search filtering.
5. **Interactive Task Management:** Controlled input form to add tasks, toggle task completion status (checkbox), and delete tasks.
6. **Sidebar Navigation Drawer:** Responsive slide-out navigation overlay.
7. **Responsive UI:** CSS Flexbox and Grid layouts optimized for Mobile (<600px), Tablet (<900px), and Desktop screens.
